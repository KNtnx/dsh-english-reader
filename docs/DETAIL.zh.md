# 对话朗读

把一段英语对话粘贴到右侧栏，它会一句一句读出来，用两个轮换的声音 —— 一个音色一个说话人。
正在朗读的那一句会高亮并滚动到视野中间。对话会存进一个小书库，每段各自记住读到哪一句，可以
在不同的对话之间来回切换并接着上次的位置继续。

两个引擎，随时可切换：

- **Edge 在线** —— 微软 Edge 的神经音色。不用安装，需要联网，文本会发给微软。
- **本地模型** —— [Kokoro-82M](https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX)
  （Apache-2.0，8200 万参数，量化后约 89 MB），在这台机器上跑。一键下载后完全不需要联网，
  文本不会离开这台机器。

## 面板在哪

- 右侧栏的「对话朗读」页签。右侧栏引导页里也有一张卡片。
- 输入框工具行左侧的耳机按钮，一下就能打开面板。

## 对话库

面板最多保留 60 段对话，每段存着标题、正文和朗读位置。库视图按新建时间倒序排列，显示句子数
和
每段读到了第几句。打开一段就接着读；点 × 删除（再点一次确认）。

**新建对话**进入编辑框。编辑已有对话后按**保存并朗读**，会替换那一段而不是新建一份副本；
如果正文有改动，它保存的位置会回到第一句 —— 旧的句子编号已经对不上了。

**标题不会被正文改动覆盖。** 新建时标题取正文第一行；之后再改正文（哪怕整段换掉）都不动标题，
要换名字用对话库那一行的「改名」。

对话库和「我的单词」存在宿主上（`$DSH_HOME/dsh-english-reader/library.json`，权限 0600），
所以每个会话、每个浏览器看到的是同一份列表。音色、宽度、字号这些偏好仍归设置它的那个浏览器。
插件第一个版本只保存一段对话，那段文本会在首次打开时自动迁移进库。

## 朗读

1. 粘贴对话，为两个角色各选一个音色、选好语速，按「开始朗读」。
2. 以「短的标签 + 冒号」开头的行（`Emma: …`、`A: …`，或全角 `：`）会变成对话轮次。标签最多
   两个词，所以带冒号的普通散文仍按散文读。前两个说话人分别用音色 A 和 B，第三个起在两个音
   色之间轮流；没有标签的行用音色 A 当旁白读。
3. 完全没有任何标签的对话，按轮次轮流用两个音色，所以粘一段没写名字的双人对话听起来也像对话。

## 这是文章还是对话

粘进来的不一定都是对话。面板会自己判断并说明：

- **对话** —— 有若干不同的短标签充当轮次。每个说话人一个音色，旁白行用音色 A。只有对话才显示
  说话人色块。
- **文章** —— 其它所有情况，包括带一句 `Note:` 的散文，以及通篇由同一个说话人念完的转写稿。
  用单音色朗读。

编辑框里的**朗读方式**可以推翻这个判断，选择会跟着那段对话一起保存。

文本粘进来时每个视觉行末尾都有硬换行，所以在切句之前，**没有结束一句的行会先和下一行接起来**，
免得一句话被合成成两截、中间硬停。空行、说话人标签、已经结束的句子都会结束一个轮次；空行同时
用来分段落，显示为额外的间距。

## 控件

| 控件 | 作用 |
| --- | --- |
| 播放 / 暂停 | 就地暂停；再按一次从同一句继续 |
| 上一句 / 下一句 | 跳一句并立刻开始读 |
| 单句循环 | 反复读当前这一句，直到你关掉 |
| 从头开始 | 回到第一句并开始读 |
| 语速 | 0.5× 到 2×，改的是播放速度，音调不变，也不会重新合成 |
| 点某一句 | 跳到那一句并开始读 |
| 对话库 / 编辑文本 | 切换视图；播放暂停 |

面板获得焦点后，<kbd>空格</kbd> 播放 / 暂停，<kbd>←</kbd> / <kbd>→</kbd> 前后一句。面板用的是
自己的键盘处理，不会把这两个键从输入框那里抢走。

播放条显示当前第几句（`7 / 24`），最后一句读完会显示「已读完」；此时按播放键从头重读。

## 翻译

每一句下面都可以带一行译文，用**衬线字体**排，所以不会和英文原文混在一起。标题栏里的翻译按钮
控制显示；第一次按下会去取，整段对话一条请求翻完，保证译文和句子一一对齐。译文跟着那段对话一起
保存，再打开不花任何代价。改动正文、或者改变「文章 / 对话」的分句方式，都会让译文作废 —— 它当初
对齐的句子编号已经对不上了。

编辑框里的**翻译来源**用来选：

| 来源 | 需要 | 说明 |
| --- | --- | --- |
| DSH 自带模型 | 什么都不用 | 默认。先选这个 DSH 已经配置好的供应商，再选该供应商下的任意模型。质量最好。 |

### TTS 来源

Edge 是内置的，删不掉。其余都是你自己添加的来源：点 **添加来源**，弹出一个居中的小窗，两种形式：

| 形式 | 你要给 | 说明 |
| --- | --- | --- |
| TTS API | 地址、协议、模型、密钥 | 协议三选一：OpenAI 兼容 `/audio/speech`、阿里云百炼原生接口、Azure 语音。只填域名即可，路径会自动探测并记住。音色是自由文本。 |

**为什么协议是必选项**：同一家服务的不同接口路径和请求体完全不同。阿里云百炼的 OpenAI 兼容前缀只支持对话和向量，语音合成走原生的 `api/v1/services/aigc/multimodal-generation/generation`，返回的还是音频下载地址。协议决定发什么请求，不是装饰。
| 本地模型 | 一个模型目录 | 用宿主自带的目录对话框指向含 `config.json` 和 `onnx/` 模型的目录。目录留空则用内置的 Kokoro 下载。 |

宿主会拒绝不像模型的目录（`400 bad-model-path`），并按目录缓存已加载的引擎——在两个本地模型之间切换时，只有目录变了才重新加载。引擎不报词时间戳时，词高亮退回按时长估算。

密钥不下发到浏览器：来自插件配置（`ttsApiKey`）或 `DSH_ENGLISH_READER_TTS_API_KEY`。地址、模型、目录、音色存在本浏览器本地存储里。同样的环境变量可预置默认端点：`DSH_ENGLISH_READER_TTS_BASE_URL`、`_MODEL`、`_VOICE`、`_FORMAT`。
## 本地模型

在引擎开关上选**本地模型**，面板会显示当前状态：

- 未下载 —— 提供**下载并使用**，开始在运行 DSH 的这台机器上下载约 89 MB 并显示进度条。
- 下载中或加载中 —— 显示百分比；下载期间请求朗读会直接提示模型正在准备，而不是干等。
- 已下载 —— 显示**可离线使用**，音色列表切换成本地音色。重启之后会显示**第一句时加载模型**：
  权重已经在磁盘上，这次运行里第一次请求朗读时把它读进内存，需要一小会儿。

本地引擎本身是**可选 peer**，默认不随插件安装。在本地模型卡片点「下载并使用」，面板会先说明将安装引擎（约 120 MB，只装一次）并下载模型（约 89 MB）；确认后由插件自动完成，取消则什么都不装。安装失败时面板会显示原因并给出手动命令。Edge 语音不受影响。

切换引擎会暂停播放并丢掉已经加载好的那一句，所以下一次按播放会用你切过去的那套引擎重新取。

模型放在 `~/.dsh/dsh-english-reader/models/`，重启后第一次用到时加载。合成在 CPU 上逐句进行；
24 核的台式机上大约一句一秒，比它生成的音频快得多，所以播放不会卡顿。

## 语音

音频片段会缓存在宿主进程（最近 64 句），所以重复听一句是瞬时的，正在播放的那一句之后还会
提前合成三句。

## 限制

- **Edge 需要联网。** 每一句的文本都会发给微软。这是非官方接口，微软随时可能改掉或关闭；届时
  面板会提示语音服务拒绝了这一句并停止。
- **本地模型只支持英语，且只跑 CPU。** 它是 Kokoro-82M，速度快但不如最好的云端音色自然；重启
  后的第一句要等模型加载。
- **同时开两个面板时按条目合并。** 各自保存的内容会由宿主按 id 合并；归类由 `folderAt` 决定，
  所以一次移动不会被没见过它的保存覆盖。已经打开的面板每两秒问一次宿主的版本号，另一处（另一个
  面板、或对话里调用的 `english_reader`）写进去的东西会自己出现，不用刷新页面。
- **清空浏览器不会清空对话库。** 对话和单词在宿主上，删 `library.json` 才是从头开始。
- **对话的判定是启发式的。** 出现两个以上不同标签、且覆盖至少四分之一的文本才算对话，否则按
  文章单音色读。散文里恰好出现两处 `词语:` 可能被误判成对话；通篇一个说话人的转写稿会按文章读
  —— 两种情况都可以用**朗读方式**改回来。
- **段落只能靠空行还原。** 没有空行的粘贴内容会连成一段，这是硬换行带来的信息损失；但跨行的断句
  仍然会被正确接回与切开。
- **一句一次请求，上限 800 字符。** 没有任何标点的长段落会超限，面板会提示这一句太长无法合成；
  加些标点断开即可。
- **只有两个来源开箱可用。** DSH 自带模型和免密钥的谷歌端点。微软与腾讯需要插件行里的密钥配置，面板填不了，所以没有作为选项列出。
- **这些路由没有鉴权。** 和其它 DSH 插件的 Web 路由一样，任何能访问 DSH 端口的人都能调用。它们
  不读文件、不持有凭据。外部调用者可以让这台机器合成语音，也能触发一次模型下载。
- **音频不落盘。** 缓存只在内存里，宿主进程重启就没了。

## 连读开关

播放条「单句循环」右侧是「连读」开关。关闭后，一句读完即停，进度停在原处，不会自动跳下一句；再次点播放从当前句继续。

## 词典

显示、中文来源、英英来源三者独立：

- **显示** 决定卡片露哪种语言（中英 / 英英 / 中文）。
- **中文来源** 可选 iciba 或模型；**英英来源** 可选 WordNet、Wiktionary、柯林斯或模型。
- 选模型时，该槽位自己的供应商与模型就在它下面展开；两个槽位可以指向不同模型。
- 只查询正在显示的语言，所以「英英」模式不会多花中文查询。
- 柯林斯密钥存在宿主机 `dictionary.json`（0600），浏览器只读到「已保存」。
- 模型释义按 `单词|来源|模型` 缓存，切换不重复消耗额度。

## 我的单词

- 列表行**左键点开即在原地展开**：中文按词性分行，英文释义带例句，末尾附收藏时的原句。
- 展开内容**跟随当前词典**：换来源或换显示语言会立刻重新解析，不会停在收藏时的旧释义。
- 收藏只记**单词和原句**，释义来自词典或缓存；两个来源都没有词条时回落到翻译。
- 三个喇叭：单词、词条例句、原句（从字典卡片搜来的词没有原句，那个喇叭是灰的）。
- 「我的单词」和「对话库」都能一键返回当前对话，两页共用阅读页的宽度与字号。
